# Class index

Generated by `scripts/gen_reference.py` from the dexpigen code; do not edit by hand.
Each file lists its classes in inheritance-tree order with their DEXPI `ComponentClass`,
bases, abstractness and own fields. The Relation column says whether a field
composes its value (`composed`) or references an object owned elsewhere (`ref`).

- [Model root and shared base](model.md): `ConceptualModel` (the root), `DexpiBaseModel` (every object's base) and `CustomAttribute`.
- [Equipment classes](equipment.md): The `Equipment` tree, `Nozzle`, `Chamber` and `CustomEquipment`.
- [Piping classes](piping.md): Piping network systems and segments, connections, nodes, valves, fittings and off-page connectors.
- [Instrumentation classes](instrumentation.md): Instrumentation functions, the control-valve assembly, signals, sensing and loops.
- [Enumerations](enumerations.md): The DEXPI enumerations used by model fields, with their members.
